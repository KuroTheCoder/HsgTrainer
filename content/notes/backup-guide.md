# Backing up and restoring your progress

Your practice sessions, mistakes, and progress live **only in your browser** — there is no account and no server holding your data. This guide shows you exactly what to do, step by step.

## Why a backup matters

If you clear your browser data, switch computers, or your phone dies, everything is gone unless you made a backup. Making a backup takes **10 seconds** — do it once now, and again every few weeks.

## How to make a backup (10 seconds)

1. Click **Settings** in the left menu.
2. Click the **Data** tab at the top of the settings page.
3. Click the blue **Export backup** button.
4. A file called something like `hsgtrainer-backup-2026-08-17.json` downloads to your **Downloads** folder (or wherever your browser puts downloaded files).
5. That's it — you have a backup.

**The important part:** move that file somewhere safe, where your computer backs things up by itself:

| Where to put it | How |
|---|---|
| Google Drive | Open drive.google.com → drag the file in |
| iCloud (iPhone/Mac) | Move the file to the iCloud Drive folder |
| OneDrive (Windows) | Move the file to the OneDrive folder |
| USB stick | Copy it to the stick, keep it in a drawer |

The file is small (a few hundred KB at most) — it takes almost no space.

## How to restore your backup

Moving to a new phone or computer, or after clearing your browser?

1. Get the backup file onto the device (download it from Drive, or copy it over).
2. Open HsgTrainer → **Settings** → **Data** tab.
3. Click **Import backup** and choose your `.json` file.
4. Your sessions, mistakes, and progress come back.

> [!warning] Import replaces what's on the device
> Importing puts the backup file's data on this browser and removes whatever practice data was already here. If you practiced on this device since the backup, export first so you don't lose it — then import the older file if you really want to.

## Answering the usual questions

> [!note] I forgot to make a backup and cleared my browser — can you recover it?
> No one can. There is no server copy. This is why the guide asks for a backup — it's the only copy that exists. If you use a synced folder (Drive, iCloud, OneDrive), the OS keeps a copy for you automatically, so future surprises cost nothing.

> [!note] I'm a teacher / parent — can I back up a student's progress for them?
> The backup belongs to the browser it was made on. To carry a student's progress to another device, export on the original device and import on the new one while signed in the same way (same browser, same device, or the same exported file). There is no cloud account to "log into".

> [!note] Does the backup include my writing essays or the question bank?
> It includes practice sessions, mistakes, and progress. Writing feedback history stays on the server automatically — nothing to do. The question bank, papers, and appearance settings don't need backing up.

> [!note] What if the file won't import?
> Make sure you pick the `.json` file that HsgTrainer exported — not a renamed copy, not a file downloaded from a random website. The error message will tell you if it's not a valid backup file.
