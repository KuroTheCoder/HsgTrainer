# HsgTrainer study notes vault

This folder is an Obsidian vault containing the study notes from
HsgTrainer (`https://hsgtrainer.pages.dev/notes`).

## How to open it in Obsidian

1. Install Obsidian from https://obsidian.md (free).
2. Unzip this folder.
3. In Obsidian: **Open folder as vault** → pick this folder.
4. All the study notes open with full Obsidian features: backlinks,
   graph view, tags, your themes and plugins.

## What's inside

- `*.md` — the study notes (same content as the website's Notes page).
- `.obsidian/` — minimal vault settings (fonts, accent color). Obsidian
  creates the rest on first open.

## Updating

Redownload the zip from the website whenever new notes are published.
